## Behind the code

I'm **Atif**, a **Full Stack Developer** based in Pakistan. I build applications with **Laravel, React, Vue.js, Quasar, and Tailwind CSS**, connecting user interfaces with APIs, databases, and business workflows. I also work with **JavaScript (Node.js)** and **Python** on the backend.

My toolkit includes **Laravel Reverb, Redis, and Kafka** for real-time and background workflows, alongside **Docker and Kubernetes** for containerized applications.

I enjoy following a feature all the way through: from the database and business logic to the API and the person using it.
